# Rock Paper Scissors

This is my Rock Paper Scissors project that I made while learning JavaScript through [The Odin Project](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors).

## About

It's a simple Rock Paper Scissors game where you play against the computer.

The game is played for 5 rounds, and the score is shown at the end.

## What I used

* HTML
* JavaScript

## What I learned

While making this project, I learned and practiced:

* Functions
* Variables
* `if / else` statements
* `Math.random()`
* Getting user input with `prompt()`
* Comparing values
* Keeping track of scores
* Calling functions
